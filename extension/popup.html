XDownload 下载助手

v1.1.0
1
安装桌面端 从 GitHub Releases 下载并安装 XDownload 桌面应用（首次启动会自动下载 yt-dlp / ffmpeg）。
2
保持应用运行 启动 XDownload 后停留在任意页面即可，无需额外设置。
3
点击视频上的「下载」按钮 视频右上角出现蓝色「下载」按钮，点击后视频自动加入桌面端下载队列。
点击「下载」后没有反应？
这通常意味着 XDownload 桌面端未安装或未运行。请先下载安装并启动桌面端，再回到页面重试。若浏览器弹出「未知协议」提示，同样说明桌面端未就绪。

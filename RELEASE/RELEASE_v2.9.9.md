> 🚀 v2.9.9 聚焦**应用内统计与日志**：新增苹果风格的**下载统计面板**（ECharts 图表）；日志查看器**移入应用内**（深色主题、ANSI 着色、内容可复制）；隐私模式补全**书签标题遮挡**；并清理浏览器版日志服务死代码。

---

## ✨ 新功能

### 📊 下载统计
- **统计面板**：设置页「统计」打开苹果风格统计页——大标题 + 数字卡片（累计下载 / 累计存储 / 成功率 / 使用天数 / 平均时长）
- **ECharts 图表**：每日下载趋势（渐变折线）、来源分布（环形图）、Top 作者（横向柱状）、Top 账号（南丁格尔玫瑰图）
- **离线可用**：ECharts 以本地文件打包（不再依赖网络 CDN），图表首次打开自动修复 WebView2 白屏时序

### 📜 日志查看器（应用内）
- **移入应用内**：设置页「软件日志」直接在应用内打开深色日志页，不再跳转浏览器（移除本地 HTTP 服务，少一个端口暴露面）
- **ANSI 着色**：时间戳半透明、等级彩色（INFO 绿 / WARN 黄 / ERROR 红），重构为 React 原生渲染确保 WebView2 下颜色生效
- **日志内容可复制**：日志行可选中复制，界面其他元素仍禁止选中
- **轮询静默**：2 秒自动刷新不再产生「get_logs」噪音日志

### 🔖 隐私模式补全
- **书签标题遮挡**：隐私开关开启时，「查看书签」弹窗标题与「书签同步」预览文本同步显示 `***`（此前仅下载页/历史页生效）

---

## 🛠 开发体验

- **清理死代码**：移除已被应用内页面替代的浏览器版日志查看器（`log_web` HTTP 服务、`open_logs_dir` 命令、前端 `openLogsDir` 绑定），代码净减约 400 行
- **移除多余依赖**：echarts 不再作为 npm 依赖安装（改用本地 vendor 文件），`package.json` / lock 清理
- **日志页优化**：ANSI 色表与解析函数提升为模块级常量，2 秒刷新不再重复分配

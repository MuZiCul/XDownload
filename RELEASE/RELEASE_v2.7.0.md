# XDownload v2.7.0 Release Notes

> ✨ v2.7.0 聚焦任务管理体验：统一多任务队列、任务面板重构、退出确认与任务状态持久化、批量下载两阶段流程、已下载拦截确认、系统播放器播放已下载视频。

---

## ✨ 新功能

- **统一多任务队列** — 删除单链接独立下载路径，所有下载（单任务/批量）统一入队调度，支持并发下载、排队等待、任务级暂停/继续/取消
- **任务面板重构** — 历史页升级为「正在下载（含进度/暂停/继续/取消）+ 下载完成（历史）」双板块，Tab「历史」改名「任务」并调整排序
- **批量下载两阶段流程** — 批量任务逐条获取视频信息（卡片显示「正在获取信息」）→ 按并发自动启动下载；获取失败自动跳过并标记「信息获取失败」
- **批量已下载拦截** — 批量添加时检测已下载链接，弹出确认弹窗逐条选择「重新下载 / 取消下载」，全部处理完弹窗自动关闭
- **退出确认与任务恢复** — 窗口 X / 托盘退出 / 设置页退出时有任务则弹窗确认；「保存进度并退出」后重启可恢复排队/暂停/下载中任务（断点续传），卡片信息（封面/作者/播放/点赞）不丢失
- **播放已下载视频** — 任务页与下载页新增「播放」按钮，调用系统默认播放器直接播放
- **批量控制** — 正在下载板块支持全部暂停 / 全部开始 / 全部删除

## 🐛 修复与优化

- **下载完成历史卡片信息为空** — 写历史时合并任务信息（info 优先，config 兜底），封面/作者/播放/点赞正常显示
- **已下载判断失效** — 修复 media id 与 status id 不一致导致的「已下载」误判，重新获取后正确显示已下载徽标
- **任务位置乱序** — 后端返回入队序号（seq），前端按序渲染，暂停/恢复/完成后任务位置稳定
- **任务卡片 UI 优化** — 封面按横竖图自动适配（横图填满/竖图模糊填充居中）、标题单行省略、进度条不独占一行、阶段标签精简（视频块/音频块/音视频合并）
- **下载页信息卡** — 封面按 16:9 放大并适配横竖图、已下载/未下载纯文字徽标、入队后按钮显示「下载中...」并禁用
- **播放路径兼容** — 历史记录相对路径自动转绝对，任意自定义下载目录均可正常播放
- **下载完成提示** — toast 显示「下载完成 + 标题」，长标题省略不撑爆窗口

## 📦 安装

### 下载预构建包

从 [GitHub Releases](https://github.com/MuZiCul/XDownload/releases/tag/v2.7.0) 下载对应平台安装包：

- **Windows**: `XDownload_2.7.0_x64-setup.exe` (NSIS) / `.msi`

### 从源码构建

```bash
# 环境要求：Rust (MSVC)、Node.js 18+、pnpm

# 开发模式
pnpm dev

# 打包构建
.\build.bat          # Windows
```

## ⚠️ 升级说明

- 从 v2.6.1 升级**无需迁移配置**
- 任务进度保存在 `config/queue.json`：勾选「保存进度并退出」后重启可继续下载
- 历史记录路径自动兼容（旧记录为相对路径时自动转绝对）

> 🚀 v2.9.5 聚焦**下载可靠性**：彻底移除断点续传（所有下载一律从头，杜绝碎文件导致的 ffmpeg 合并异常），重做**退出确认弹窗**（最小化到托盘 / 真正退出由你决定），并修复多个队列与查重 bug。

---

## 🐛 关键修复

- **断点续传彻底移除**：删除 `resume_support` 开关；每次下载前清空缓存目录 + 强制从头下载（暂停→开始、失败重试、重启恢复均从头）
- **碎文件不再积累**：暂停 / 取消任务后立即清理该任务的暂存缓存目录，残分片与 `.part` 不会残留
- **退出不误报失败**：保存进度退出后重启，正在下载的任务不再被记录为"下载失败"（kill 的 worker 静默收尾）
- **删除任务队列停滞**：删除正在下载的任务后，等待中的任务立即开始（此前会卡住）
- **深链查重**：扩展发送的链接若已下载过，弹出确认框（重新下载 / 取消），不再重复入队
- **历史来源显示错误**：修复 `list_download_history` 漏传 source 字段导致全部显示「单链」

## ✨ 新功能 / 改进

### 退出确认弹窗
- 关闭窗口（X）总是弹窗：**最小化到托盘 / 真正退出**（无任务也弹窗）
- 托盘退出只显示「退出 + 取消」；设置页退出与 X 同逻辑
- 有任务且未自动保存时提供「保存进度并退出 / 直接退出 / 最小化 / 取消」
- 精简模式文案独立，不再误显示"有任务正在执行"

### 任务页动态分栏
- 活跃任务 ≥ 2 个：上 50% / 下 50%
- 0~1 个：上 30% / 下 70%（历史区获得更多空间）

### 来源徽标增强
- 新增**深链**来源（独立于批量 / 书签），四种来源一眼可辨

### 设置页按钮配色
- hover 配色重构：普通按钮中性灰、退出按钮淡红、隐私按钮琥珀，卡片光晕改中性（不再与 Tab 选中蓝色撞色）

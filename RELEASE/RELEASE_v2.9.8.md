> 🚀 v2.9.8 聚焦**设置体验重构与账号识别**：彻底移除「配置保存/应用/导入/导出」体系，所有设置**更改即自动保存**；代理能力增强（系统代理重开恢复、输入校验、开关自动联动）；书签管理新增**登录用户名识别**（Cookie 指纹缓存）与「获取/重载用户」按钮。

---

## ✨ 新功能 / 改进

### ⚙️ 设置
- **设置即自动保存**：移除配置保存 / 应用 / 导入 / 导出 / 恢复默认体系，所有设置项（下载目录、代理、Cookies、多任务、HLS、语言）**改动即时保存并生效**，不再有保存/应用按钮
- **保存竞态修复**：新增全局串行「读-改-写」机制，快速连续改动多个设置不再互相覆盖
- **设置标签精简**：并发数 / 重试次数 / 持久化 / 防休眠 / 限速 / 使用代理，完整说明移入问号提示
- **问号提示统一**：提示弹窗统一为「总述 + 条目前缀 + 悬挂缩进」风格

### 🌐 代理
- **系统代理重开恢复**：修复系统代理关闭后再打开无法恢复的问题（此前开关会一直禁用）
- **手动代理强制应用**：系统 → 手动切换即时生效
- **输入校验**：端口仅允许 1-65535（超限/非数字直接拒输），主机地址仅允许合法字符
- **开关自动联动**：「使用代理」开关随代理状态实时同步（代理关闭自动关开关）

### 🔖 书签管理
- **登录用户名识别**：标题显示当前 x.com 登录用户（`● 已登录用户: @xxx`），基于 Cookie 指纹缓存，重启后浏览器来源不变则不重复探测
- **获取 / 重载用户**：按钮手动刷新；未获取到用户时显示红色状态提示，同步/查看书签自动禁用
- **未登录保护**：无法识别用户时禁用同步与查看，避免无效操作

### 🛠 其他
- **日志查看器**：浏览器标签页补上应用图标（favicon）
- **日志增强**：ffmpeg 缓存命中、代理开关变更、队列持久化/防休眠开关变更均有日志记录
